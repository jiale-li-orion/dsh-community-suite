# @deepseek-ai/dsh-workbench

[English](README.md) | 中文

共享工作台状态服务。唯一的值——工作台栏是否打开、选中了哪个面板——是两个平面共同的唯一权威：浏览器手势以 Remote 调用到达，`dsh-tool-workbench` 的工具写入同一个值，每次提交都发出 `workbench/changed`，Web 客户端通过转发事件白名单消费它。该服务还回答文件面板的目录列举，以调用会话记录的工作目录为围栏、经 `ctx.fs` 能力解析，因此面板看到的正是 agent 操作的那棵树。每个文件条目携带 `contentTypeForPath` 选出的媒体类型，列举本身给出提供其字节的 `fileRoute`，于是查看器链与字节路由读的是同一套词表。

## 模型体验

无，因为该包持有浏览器查看状态与一次受围栏保护的目录读取；面向模型的投影位于 `dsh-tool-workbench`。

#### KV Cache 影响

无；该包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **围栏是会话记录的工作目录**：没有它的会话无法列举，且没有当前会话时工作台不显示文件。
- **视图是进程全局的**：每个已连接的浏览器与 agent 看到同一份打开/选中状态；按客户端隔离的视图暂缓到有消费方需要时。
- **列举是只读的**：从工作台编辑或创建文件属于后续阶段。
- **媒体类型按扩展名判断**：内容与扩展名不符的文件按名字定型；这正是浏览器需要的 `Content-Type` 与查看器路由依据。
