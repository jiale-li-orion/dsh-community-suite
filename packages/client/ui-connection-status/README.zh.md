# @deepseek-ai/dsh-client-ui-connection-status

[English](README.md) | 中文

Web 连接状态归属包：向横跨整个框架的 `shell.overlay` 列表贡献一条条目，用于报告连接丢失与恢复。数据完全来自 connection 插件发布的连接相位（[`dsh-client-connection`](../connection/README.md)），因此本包不发 RPC、自己不持有任何状态。

连接正常时该条目不渲染，流循环尚未启动时也不渲染，所以正常路径下 overlay 层始终是空的。当某一代连接已死时，它显示一行说明正在重连的状态文字。这一行是 `status` 实时区域，而 overlay 层本身对指针透明，因此永远不会挡住其下的输入框。

连接断开在别处是不可见的：runtime 在一代连接死亡的瞬间丢掉该代的作用域交互状态，重连后再重建会话基线，全程不做任何提示——对于经中继网络接入的手机，这与"应用卡死"无法区分。报告连接相位只是呈现；任何可能作用在过期连接上的动作仍归各自的插件所有，因此这里不会在恢复时重发消息、重新批准请求或安装插件。

样式只使用 token；文案走本包自己的 `connection` 语言命名空间。生命周期与回收遵循[Web 客户端架构 Agent Note](../../../.agents/notes/implemented/architecture/2026-07-19-gui-web-client-architecture.md)。

## 模型体验

无。本包只为人类渲染一个客户端连接相位，不触及任何 prompt、消息、schema、流或工具结果。重连本身对模型不可见：会话日志保留模型产出，恢复后的客户端从该日志重建视图。

#### KV Cache 影响

无；本包从不组装或发送 provider 请求。

## 已知限制与暂缓事项

- **该相位只覆盖一条流连接** —— 它报告的是浏览器与 host 之间的连接，而不是 host 上正在运行的工作是否健康。手机掉网会看到这行字；host 继续工作不受它影响，这正是有意的区分。
- **恢复没有成功态** —— 下一次握手完成时这行字就消失。移开视线的用户无法从这条条目判断重连是否成功；要给出"已重连"确认，需要时间戳以及"停留多久"的归属方。
